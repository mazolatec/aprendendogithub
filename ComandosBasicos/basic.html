📦 Inicialização
  git init 
  Initialize a new Git repository
  # Cria um repositório vazio no diretório atual
🔍 Verificar Status
  git status 
  Show the working tree status
  # Exibe mudanças e arquivos rastreados/não rastreados
➕ Adicionar Arquivos
  git add . 
  Add file contents to the staging area
  # Adiciona todos os arquivos ao índice (stage) para o próximo commit

  git add index.html 
  Add specific file to the staging area
  # Adiciona apenas o arquivo especificado ao stage
💾 Commits
  git commit -m "mensagem" 
  Record changes to the repository
  # Salva as mudanças com uma mensagem descritiva

  git commit --amend -m "Nova mensagem do commit" 
  Edit the last commit message
  # Edita a mensagem do último commit

  git commit --amend --no-edit 
  Amend last commit without changing message
  # Atualiza arquivos do último commit mantendo a mesma mensagem
♻️ Reset / Desfazer
  git reset --soft HEAD~1 
  Undo last commit but keep changes staged
  # Desfaz o commit mas mantém as alterações prontas para novo commit

  git reset --hard HEAD~1 
  Undo and discard all changes
  # Remove o último commit e descarta todas as alterações locais
🧭 Histórico
  git log 
  Show commit history
  # Exibe histórico completo de commits

  git log --oneline --graph --decorate 
  Compact view with graph
  # Mostra histórico resumido com gráfico e nomes de branches
🪄 Mover e Remover Arquivos
  git mv rodape.css css/rodape.css 
  Move or rename a file
  # Move o arquivo rodape.css para a pasta css e já deixa no stage

  git rm style.css 
  Remove file and stage deletion
  # Remove o arquivo do diretório e prepara a remoção para commit
🌿 Branches
  git branch 
  List all local branches
  # Lista todas as branches do projeto

  git checkout -b nova-feature 
  Create and switch to new branch
  # Cria e muda para a nova branch

  git merge nova-feature 
  Merge branch into current
  # Une alterações da branch nova-feature na branch atual
🌐 Repositório Remoto
  git remote add origin https://github.com/usuario/repositorio.git 
  Connect local repo to remote
  # Associa o repositório local ao GitHub (remoto principal)

  git push -u origin main 
  Push branch to remote (set upstream)
  # Envia a branch local e define o acompanhamento remoto

  git pull 
  Fetch and merge changes from remote
  # Baixa e integra atualizações do repositório remoto
⚙️ Configurações
  git config --global user.name "Seu Nome" 
  Set global username
  # Define o nome de usuário global
